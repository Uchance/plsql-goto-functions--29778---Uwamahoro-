REFRECTION



In this project, I learned how to create and use PL/SQL functions in Oracle Database. I learned that a function can accept input, process it, and return a value.

I created functions for calculating annual salary, years of service, tax, and department names. I also learned how functions can be used directly inside SQL queries.

The Payroll Validator helped me understand how different functions can work together to validate employee payroll information.

One challenge I faced was writing and executing SQL statements correctly in SQL*Plus. I learned that each SQL statement must be executed properly and that the semicolon is important.

Overall, the assignment was about function and goto statement.
